PANDUAN MEMASUKKAN FOTO / SCAN SERTIFIKAT:
===========================================

1. Anda dapat menyimpan file gambar/scan sertifikat asli Anda (format .jpg, .jpeg, atau .png) di dalam folder ini:
   Portofolio_Arsyandi/public/certificates/

   Contoh penamaan file:
   - cert-dbs-2026.jpg
   - cert-dbs-2025.jpg
   - cert-mix-academy.jpg
   - cert-educa-studio.jpg
   - cert-educourse.jpg
   - cert-tokopedia.jpg
   - cert-plan.jpg

2. Buka file data portofolio:
   Portofolio_Arsyandi/src/data/portfolioData.js

3. Pada bagian `certifications`, ganti properti `image` sesuai file Anda, contoh:
   image: "/certificates/cert-dbs-2026.jpg",

Sertifikat akan langsung tampil di kolom grid halaman Sertifikasi lengkap dengan tombol pratinjau zoom/lightbox!
